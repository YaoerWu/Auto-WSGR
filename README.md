# 安装方法
1. 安装[git](https://git-scm.com/install/windows)
2. 安装本脚本 `pip install git+https://github.com/YaoerWu/Auto-WSGR`或者直接使用gui [ilevalser/AutoWSGR_GUI](https://github.com/ilevalser/AutoWSGR_GUI)
3. 按照以前的方法使用，如果你不知道以前的方法，那么你可以直接用新版[OpenWSGR/AutoWSGR](https://github.com/OpenWSGR/AutoWSGR)与他的gui [yltx/AutoWSGR-GUI](https://github.com/yltx/AutoWSGR-GUI)
